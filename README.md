
# PORTAL DO EMPREGO

Plataforma nacional de empregabilidade, busca de vagas e recrutamento.

## Objetivo

Conectar candidatos e empresas em um ambiente único, com cadastro profissional gratuito, banco privado de currículos e ferramentas de recrutamento por assinatura.

## Módulos previstos

- Portal público de vagas e busca avançada.
- Cadastro de candidatos e interesses profissionais.
- Upload e armazenamento privado de currículos.
- Cadastro e verificação de empresas.
- Banco de talentos com acesso empresarial por assinatura.
- Sistema próprio de recrutamento (ATS).
- Gestão de candidaturas e entrevistas.
- Recomendações de compatibilidade profissional.
- Administração, auditoria e proteção de dados.

## Tecnologias planejadas

- Next.js
- React e TypeScript
- PostgreSQL
- Prisma ORM
- Docker
- GitHub
- Render

## Segurança

Os currículos serão privados por padrão. O acesso empresarial dependerá de autenticação, autorização, assinatura válida e registro de auditoria.

## Desenvolvimento

O projeto será implementado por fases, com testes e validação antes de cada implantação.
